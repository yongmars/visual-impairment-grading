# 視覚障害等級判定

眼科スタッフ・視能訓練士が、視力および視野検査結果から視覚障害等級、指数、総合等級を確認するための業務用PWAです。

## 主な機能

- 矯正視力による視力障害等級判定
- ゴールドマン型視野計（I/4・I/2）による視野障害等級判定
- 自動視野計（エスターマン・10-2）による視野障害等級判定
- 視力・視野指数の合算による総合等級判定
- 入力値、計算式、該当条件、ルールIDの表示
- 画面移動・再読込後も編集中の入力を端末内に保持
- 判定結果の端末内保存とオフライン起動
- 保存した履歴の入力データを判定画面へ再読込

## 開発

```bash
npm install
npm run dev
```

## 検証

```bash
npm test
npm run build
```

## 判定基準

- ルールID：`jp-visual-disability-2018-07:v1`
- 基準確認日：2026-08-17

本アプリは計算と確認を補助するものであり、最終的な診断・認定は最新の身体障害認定基準および指定医・認定機関の判断を優先します。
